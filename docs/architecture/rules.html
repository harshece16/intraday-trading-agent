One engine tick

A tick that throws is caught and logged; the loop continues. A tick that runs past 120 seconds gets every thread's stack dumped once.

The entry pipeline and where it stops today

The confidence score is the setup's local score (out of 100) times a system multiplier. The multiplier is 0.25 while any Scorecard row fails. The committed backtest evidence row fails (−0.356R a trade, t −3.59), so the score tops out at 25 and no automatic entry can pass 60. That is the designed behaviour, not a fault.

The books

While a Jev round is open, its page shows a live mark of the positions at Kite's prices. The mark is never stored and never scored.

stateDiagram-v2
    direction LR
    state "Momentum book" as MB {
        [*] --> waiting_for_month_end
        waiting_for_month_end --> active: first session of a month
        active --> active: daily mark, monthly rebalance
        active --> switched_off: excess below the band from month 6
        switched_off --> [*]
    }
    state "Jev book, one day" as JB {
        [*] --> deciding: morning round starts
        deciding --> no_live_prices: Kite not connected
        deciding --> jev_unavailable: TypeSafe error or no key
        deciding --> open: answers recorded
        open --> closed: square-off, scored after costs
    }

The evidence pipeline

Trials of record: 127. Passed: 1 (trial 120; re-run on repaired prices as trial 126, it survives narrowly, with a smaller edge). Held-out window: spent once, for the momentum family.

flowchart TD
    Idea(["Idea"]) --> Sweep["Literature and community sweep<br/>what is already known?"]
    Sweep --> Pre["Pre-registration committed<br/>hypothesis, rule, sample, costs, pass rule"]
    Pre --> Rev["Reviewer reads it<br/>amendments before any run"]
    Rev --> S0["Stage 0<br/>data checks, no returns read"]
    S0 -->|"cannot be powered"| Wd(["Withdrawn, no trial spent"])
    S0 --> Run["One run on the selection sample<br/>before 2026-01-02"]
    Run --> Res["Results file + ledger row<br/>trial count goes up"]
    Res --> Gate{"Family bar: Bonferroni t,<br/>corrected DSR at least 0.95,<br/>both halves, last 3 years"}
    Gate -->|fail| Closed(["Closed. No retries, no re-grading"])
    Gate -->|pass| Conf["Confirmations: unseen stocks,<br/>then the 2026 held-out window, once"]
    Conf -->|fails| Closed
    Conf -->|confirms| Paper["Paper book with a switch-off band"]
    Paper --> Own{"Owner decision"}
    Own -->|"only the owner"| Real(["Real money"])

What happens on a trading day

All times are IST. Kite logs out at 06:00 every day, so reconnect before 09:15.

TimeWhat happensNeeds Kite
06:00Zerodha expires every Kite session
First tick of the dayPre-market read: daily bars only, ranks a watchlistNo
08:45Pre-open check. One error-level alert if Kite isn't connectedProbes it
09:15Phase open. Scanner every 5 minutes. Stops are watched on ticks and on every pollFor live prices
09:15 to 09:30ETF window samplingYes
09:15 to 15:08Order-book sample of the watchlist on every tickYes
09:30 to 14:30Entry window for the checklist and the review queue
09:45Jev round: one request per shortlisted stock, paper entries at the live priceYes
15:00 to 15:30ETF window samplingYes
15:08Phase square_off_window. Every cash and F&O position is closed. Jev positions are closed and scoredYes for Jev
15:30Phase closed. Session summary is logged
19:30 to 23:30Evening job: download the bhavcopy, rebuild prices, mark the momentum book. On a month's first session, rebalanceNo
