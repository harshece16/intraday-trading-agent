## How a decision is taken

At each decision point the main session gathers the evidence and spawns a **decision agent**. The agent reads this charter, the evidence, and the pre-registrations it names, and returns one decision: `{"id", "at", "question", "evidence", "options", "decision", "why", "rules_applied", "reversible"}`. The main session records it, then acts. If the decision would break a hard limit below, the main session does not act, records why, and takes the nearest decision that keeps the limits.

## Hard limits (no decision can cross these)

1. **No real money.** Nothing places a live order. The engine stays in paper mode. F&O stays off.
2. **No gate is loosened, and no threshold, window, feature or target is changed after a number is seen.** A change is made only by a dated amendment written before the run it governs.
3. **One run per pre-registered hypothesis.** A re-run only for a crash before any statistic, or a declared bug fixed with both runs recorded.
4. **The 2026 held-out window is not read tonight.** Spending it is the owner's decision; "if positive" is read as permission to prepare, not to spend it.
5. **Nothing enters the engine's decision path** (scanner, checklist, review queue, entries, sizing) tonight. "Add it to Trader Sahab" means, at most: the Kronos page, the live shadow, and a pre-registered trial ready for the owner. A paper book that trades on a forecast needs the look's gate, a trial's pass and a confirmation, which cannot all happen in one night.
6. **Every combination tried is counted as a trial**, and the combination search is judged at its full trial count. "See a profit" is answered with the number that survives that correction, never with the best of the search.
7. **The engine's machine (the Mac) is not loaded during the session** (08:30–15:45 IST). Heavy work runs on the PC. The Kronos shadow on the Mac is the one exception, already running.
8. **No secret leaves the Mac.** The PC gets no dashboard key and no Kite session.
